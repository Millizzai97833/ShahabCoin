
# ShahabCoin (SHC)

ShahabCoin is an experimental, open-source blockchain project inspired by Bitcoin.

## Proposed specifications

- Name: ShahabCoin
- Symbol: SHC
- Target maximum supply: 21,000,000 SHC
- Target block interval: 150 seconds
- Initial implementation: Python
- Current status: Experimental development

## Features in this prototype

- SHA-256 block hashing
- Linked blocks
- Blockchain integrity validation
- Basic command-line interface
- Automated tests

## Planned development

1. Signed transactions and wallets
2. Double-spend prevention
3. Proof-of-work consensus
4. Difficulty adjustment
5. Supply and block-reward enforcement
6. Peer-to-peer networking
7. Public testnet
8. Independent security audit

## Disclaimer

This is experimental software. It is not a production-ready cryptocurrency.
No real-value SHC has been issued by this project. Do not use it to store
funds or represent prototype balances as real money.
